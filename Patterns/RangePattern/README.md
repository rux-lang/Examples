# RangePattern

Match a whole run of integers in one arm with `1..=9 =>` and `0..10 =>`.

**You'll need:** [Match](https://rux-lang.dev/docs/learn/match), [Range](https://rux-lang.dev/docs/learn/range), [MatchExpression](https://rux-lang.dev/docs/learn/match-expression)

```sh
rux run
```

```text
204 success
302 redirection
404 client error
99 not a status code
0 is none
9 is a few
10 is dozens
250 is hundreds
-3 is a debt
```

Read the lesson: https://rux-lang.dev/docs/learn/range-pattern
