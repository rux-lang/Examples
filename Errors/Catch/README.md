# Catch

Recover from a failure with `catch`, giving one arm per error case.

**You'll need:** [Outcome](https://rux-lang.dev/docs/learn/outcome), [VariantMatch](https://rux-lang.dev/docs/learn/variant-match), [Guard](https://rux-lang.dev/docs/learn/guard)

```sh
rux run
```

```text
'7' reads as 7
'O' reads as 0
'l' reads as 1
'x' reads as -1
'#' reads as -1
' ' reads as -1
```

Read the lesson: https://rux-lang.dev/docs/learn/catch
