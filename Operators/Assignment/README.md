# Assignment

Update a variable in place with `+=` and friends, and step it by one with `++` and `--`.

**You'll need:** [Mutable](https://rux-lang.dev/docs/learn/mutable), [Arithmetic](https://rux-lang.dev/docs/learn/arithmetic)

```sh
rux run
```

```text
start      10
+= 5       15
-= 3       12
*= 4       48
/= 5       9
%= 5       4
++         5
-- twice   3
price      3.5
count++ gave 1, count is now 2
++count gave 3, count is now 3
```

Read the lesson: https://rux-lang.dev/docs/learn/assignment
