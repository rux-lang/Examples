# Arithmetic

Calculate with `+ - * / %`, and see why `17 / 5` is 3 for integers but 3.4 for floats.

**You'll need:** [Variable](https://rux-lang.dev/docs/learn/variable), [Integer](https://rux-lang.dev/docs/learn/integer), [Float](https://rux-lang.dev/docs/learn/float), [Console](https://rux-lang.dev/docs/learn/console), [Convert](https://rux-lang.dev/docs/learn/convert)

```sh
rux run
```

```text
17 + 5 = 22
17 - 5 = 12
17 * 5 = 85
17 / 5 = 3
17 % 5 = 2
-17 / 5 = -3
-17 % 5 = -2
17.0 / 5.0 = 3.4
17.0 % 5.0 = 2.0
17 / 5 as floats = 3.4
uint8 250 + 10 = 4
```
