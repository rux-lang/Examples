# Comparison

Compare two values with `== != < <= > >=` and get a `bool` back.

**You'll need:** [Arithmetic](https://rux-lang.dev/docs/learn/arithmetic), [Boolean](https://rux-lang.dev/docs/learn/boolean), [Character](https://rux-lang.dev/docs/learn/character)

```sh
rux run
```

```text
17 == 5  is false
17 != 5  is true
17 <  5  is false
17 <= 5  is false
17 >  5  is true
17 >= 5  is true
age 18 is adult: true
'Z' < 'a'  is true
0.1 + 0.2 == 0.3  is false
0.1 + 0.2 >  0.3  is true
```

Read the lesson: https://rux-lang.dev/docs/learn/comparison
