# Pointer

**You'll need:** [Mutable](https://rux-lang.dev/docs/learn/mutable), [Reference](https://rux-lang.dev/docs/learn/reference), [MutableReference](https://rux-lang.dev/docs/learn/mutable-reference)

```sh
rux run
```

