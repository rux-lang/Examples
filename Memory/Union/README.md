# Union

Lay several members over one piece of storage, and keep track yourself of which member holds a value.

**You'll need:** [Layout](https://rux-lang.dev/docs/learn/layout), [Enum](https://rux-lang.dev/docs/learn/enum), [Variant](https://rux-lang.dev/docs/learn/variant), [Match](https://rux-lang.dev/docs/learn/match)

```sh
rux run
```

```text
sizeof(Payload)  8
sizeof(AllThree) 24
whole number 42
real number  0.5
flag         true
real number  2.25
```
