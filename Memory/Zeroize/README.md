# Zeroize

Wipe a secret with `Zeroize`, a clear that the compiler promises never to optimize away.

**You'll need:** [RawMemory](https://rux-lang.dev/docs/learn/raw-memory), [Pointer](https://rux-lang.dev/docs/learn/pointer), [Layout](https://rux-lang.dev/docs/learn/layout), [Copy](https://rux-lang.dev/docs/learn/copy)

```sh
rux run
```

```text
pin accepted: true
pin after Zeroize: 0 0 0 0
the earlier copy:  4 7 1 9
```

Read the lesson: https://rux-lang.dev/docs/learn/zeroize
