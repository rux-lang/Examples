# OutParameter

Return an answer through a `&var T` out-parameter, and see why returning an optional `T?` is usually the better choice.

**You'll need:** [Pointer](https://rux-lang.dev/docs/learn/pointer), [MutableReference](https://rux-lang.dev/docs/learn/mutable-reference), [Optional](https://rux-lang.dev/docs/learn/optional), [Coalesce](https://rux-lang.dev/docs/learn/coalesce)

```sh
rux run
```

```text
3 of 4 is 75%
1 of 0, flag ignored: 75%
300 into int8: lost true, wrote 44
optional: 75% and -1%
```

Read the lesson: https://rux-lang.dev/docs/learn/out-parameter
