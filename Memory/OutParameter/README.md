# OutParameter

Return an answer through a `*var T` parameter, and see why a fallible `T ! E` is usually the better choice.

**You'll need:** [Pointer](https://rux-lang.dev/docs/learn/pointer), [Fallible](https://rux-lang.dev/docs/learn/fallible), [CatchFallback](https://rux-lang.dev/docs/learn/catch-fallback)

```sh
rux run
```

```text
3 of 4 is 75%
1 of 0, flag ignored: 75%
300 into int8: lost true, wrote 44
fallible: 75% and -1%
```

Read the lesson: https://rux-lang.dev/docs/learn/out-parameter
