# Greetings

Print "Hello World" in twelve languages from an array of strings, and see that Unicode text works out of the box.

**You'll need:** [Hello](https://rux-lang.dev/docs/learn/hello), [Array](https://rux-lang.dev/docs/learn/array)

```sh
rux run
```

```text
Hello World
你好，世界
नमस्ते दुनिया
Hola Mundo
Bonjour le monde
مرحبا يا عالم
হ্যালো বিশ্ব
Привет мир
Olá Mundo
سلام دنیا
Привіт світ
🐯🐶🐱🐭
```
