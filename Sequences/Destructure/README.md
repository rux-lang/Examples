# Destructure

Unpack a tuple into named bindings in one step with `let (x, y) = pair;`, including nested patterns
and `_`.

**You'll need:** [Tuple](https://rux-lang.dev/docs/learn/tuple)

```sh
rux run
```

```text
x 3 y 4
17 / 5 is 3 remainder 2
highest reading 15
padded range 3..=16
from 0,0 to 6,8
```

Read the lesson: https://rux-lang.dev/docs/learn/destructure
