# ArrayRepeat

Build an array of many equal elements with `[0; 16]`, and see that the repeated value is evaluated
only once.

**You'll need:** [Array](https://rux-lang.dev/docs/learn/array), [Function](https://rux-lang.dev/docs/learn/function)

```sh
rux run
```

```text
zeros: length 16, first 0, last 0
Roll called
rolls: 4 4 4 4
ending in 0: 1
ending in 2: 4
ending in 5: 1
ending in 7: 2
```

Read the lesson: https://rux-lang.dev/docs/learn/array-repeat
