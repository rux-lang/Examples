# Boolean

Hold a yes-or-no value with `true`, `false` and `bool`, and meet the sized boolean types.

**You'll need:** [Variable](https://rux-lang.dev/docs/learn/variable), [Integer](https://rux-lang.dev/docs/learn/integer)

```sh
rux run
```

```text
ready     true
finished  false
visible   true
bool8     true
bool16    false
bool32    true
bool64    false
```

Read the lesson: https://rux-lang.dev/docs/learn/boolean
