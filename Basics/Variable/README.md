# Variable

Name a value with `let`, and let the compiler infer its type from the value.

**You'll need:** [Hello](https://rux-lang.dev/docs/learn/hello), [Comment](https://rux-lang.dev/docs/learn/comment)

```sh
rux run
```

```text

price     4.99
language  Rux

small     100

next year 2027
```
