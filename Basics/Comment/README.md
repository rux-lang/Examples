# Comment

Write the three kinds of comment — `//`, `/* */` and `///` — and see that block comments nest.

**You'll need:** [Hello](https://rux-lang.dev/docs/learn/hello)

```sh
rux run
```

```text
Comments never reach the program.
A block comment can sit inside a call.
// is not a comment here
/* and neither is this */
```

Read the lesson: https://rux-lang.dev/docs/learn/comment
