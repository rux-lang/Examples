# When

Choose code while compiling with `when` and `else when`, and see that the branches it skips are never even resolved.

**You'll need:** [Const](https://rux-lang.dev/docs/learn/const), [If](https://rux-lang.dev/docs/learn/if), [Function](https://rux-lang.dev/docs/learn/function)

```sh
rux run
```

```text
Compiled with Rux 0.4.0
Release channel: preview
when picked this branch while compiling
```

The version numbers are those of the compiler that built the program.

Read the lesson: https://rux-lang.dev/docs/learn/when
