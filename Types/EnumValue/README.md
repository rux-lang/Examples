# EnumValue

Give enum cases chosen numbers, and convert between a case and its number with `as`.

**You'll need:** [Enum](https://rux-lang.dev/docs/learn/enum), [Convert](https://rux-lang.dev/docs/learn/convert)

```sh
rux run
```

```text
Ok          is 200
Created     is 201
NotFound    is 404
ServerError is 500
404 means not found: true
NotFound is an error: true
Created is an error:  false
404 is a known status: true
418 is a known status: false
```

Read the lesson: https://rux-lang.dev/docs/learn/enum-value
