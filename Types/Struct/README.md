# Struct

Group named fields into a type of your own, and build values of it with a struct literal.

**You'll need:** [Tuple](https://rux-lang.dev/docs/learn/tuple), [Function](https://rux-lang.dev/docs/learn/function)

```sh
rux run
```

```text
origin  (0, 0)
corner  (5, 2)
box     at (5, 2), 4 by 3
cursor  (10, 6)
moved   (7, 10)
cursor  (10, 6)
```

Read the lesson: https://rux-lang.dev/docs/learn/struct
