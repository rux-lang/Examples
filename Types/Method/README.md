# Method

Give a type its own functions with `extend`, and call them on a value as `value.Method()`.

**You'll need:** [Struct](https://rux-lang.dev/docs/learn/struct), [Reference](https://rux-lang.dev/docs/learn/reference)

```sh
rux run
```

```text
card area        54.0
envelope area    121.0
coin area        4.91
card square      false
envelope square  true
card in envelope true
envelope in card false
```

Read the lesson: https://rux-lang.dev/docs/learn/method
