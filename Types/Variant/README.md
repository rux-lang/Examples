# Variant

Declare and build cases that carry data of their own.

**You'll need:** [Enum](https://rux-lang.dev/docs/learn/enum), [Struct](https://rux-lang.dev/docs/learn/struct)

```sh
rux run
```

```text
same case, same data       true
same case, different data  false
different cases            false
same fields                true
Measure(5.0, 5.0) exact    true
Measure(9.0, 1.0) missing  true
```

Read the lesson: https://rux-lang.dev/docs/learn/variant
