# Enum

Declare a type whose values are a fixed list of named cases.

**You'll need:** [MatchExpression](https://rux-lang.dev/docs/learn/match-expression), [Method](https://rux-lang.dev/docs/learn/method)

```sh
rux run
```

```text
start facing north
turn 1: facing east
turn 2: facing south
turn 3: facing west
turn 4: facing north
back to north: true
facing east:   false
```

Read the lesson: https://rux-lang.dev/docs/learn/enum
