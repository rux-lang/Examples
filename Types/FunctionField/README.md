# FunctionField

Store a function in a struct field, so a value carries its behaviour with it.

**You'll need:** [Callback](https://rux-lang.dev/docs/learn/callback), [Method](https://rux-lang.dev/docs/learn/method)

```sh
rux run
```

```text
7 + 3 = 10
7 - 3 = 4
7 * 3 = 21
7 max 3 = 7
through the field: 42
6 ? 4 = 10
6 ? 4 = 24
```

Read the lesson: https://rux-lang.dev/docs/learn/function-field
