# TypeAlias

Give an existing type a second name with `type`, and see why that name is not a new type.

**You'll need:** [Struct](https://rux-lang.dev/docs/learn/struct), [Slice](https://rux-lang.dev/docs/learn/slice)

```sh
rux run
```

```text
100.0C is 212.0F
sum of bytes 10
row 10 20 30
this compiles and is wrong: 212.0F treated as Celsius is 413.6F
```

Read the lesson: https://rux-lang.dev/docs/learn/type-alias
