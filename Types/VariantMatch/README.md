# VariantMatch

Match a variant and bind the data its case carries.

**You'll need:** [Variant](https://rux-lang.dev/docs/learn/variant), [MatchExpression](https://rux-lang.dev/docs/learn/match-expression)

```sh
rux run
```

```text
at (3, 0), cost so far 3
at (3, 0), cost so far 4
at (7, 1), cost so far 12
at (7, 3), cost so far 14
stopped
at (7, 3), cost so far 14
```

Read the lesson: https://rux-lang.dev/docs/learn/variant-match
