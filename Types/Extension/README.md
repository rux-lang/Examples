# Extension

Add methods to a type you did not write, from `int` to the slice `int[..]`.

**You'll need:** [Method](https://rux-lang.dev/docs/learn/method), [Slice](https://rux-lang.dev/docs/learn/slice)

```sh
rux run
```

```text
42 is even:        true
130 clamped:       100
sum of all:        52
even scores:       3
sum of the last 3: 33
```

Read the lesson: https://rux-lang.dev/docs/learn/extension
