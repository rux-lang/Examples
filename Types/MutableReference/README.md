# MutableReference

Lend a value with `&var T`, so a function can change the caller's value in place.

**You'll need:** [Reference](https://rux-lang.dev/docs/learn/reference), [Array](https://rux-lang.dev/docs/learn/array)

```sh
rux run
```

```text
Alice: balance 175, deposits 2
Bob: balance 25, deposits 1
Alice: balance 105, deposits 2
Bob: balance 95, deposits 1
points: 2 10 20 100
```

Read the lesson: https://rux-lang.dev/docs/learn/mutable-reference
