# Reference

Borrow a value with `&T`, so a function can read it without copying it.

**You'll need:** [Struct](https://rux-lang.dev/docs/learn/struct)

```sh
rux run
```

```text
kitchen: 3.5 by 4.0 metres, 14.0 square metres
hall: 1.5 by 6.0 metres, 9.0 square metres
chosen: the kitchen
widest: 3.5 metres
```

Read the lesson: https://rux-lang.dev/docs/learn/reference
