# Range

Describe a run of integers with `a..b` or `a..=b`, read its bounds, and spot an empty range.

**You'll need:** [While](https://rux-lang.dev/docs/learn/while), [Comparison](https://rux-lang.dev/docs/learn/comparison)

```sh
rux run
```

```text
digits: start 0, end 10 (excluded)
die:    start 1, end 6 (included)
10 digits
6 faces
7 is a digit: true, a face: false
5..5 holds 0 values, 5..=5 holds 1
window: start 3, end 7
hours:  start 0, end 24
faces: 1 2 3 4 5 6
```
