# Loop

Repeat with `loop`, which has no condition and ends only through `break`.

**You'll need:** [While](https://rux-lang.dev/docs/learn/while), [DoWhile](https://rux-lang.dev/docs/learn/do-while)

```sh
rux run
```

```text
6 -> 3 -> 10 -> 5 -> 16 -> 8 -> 4 -> 2 -> 1
6 reaches 1 in 8 steps
adding odd numbers up to 15 passes 50, at 64
```

Read the lesson: https://rux-lang.dev/docs/learn/loop
