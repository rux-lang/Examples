# If

Run a block only when a condition holds, and pick between two blocks with `else`.

**You'll need:** [Comparison](https://rux-lang.dev/docs/learn/comparison), [Logical](https://rux-lang.dev/docs/learn/logical)

```sh
rux run
```

```text
warm enough for a walk
bring a jacket
take an umbrella
wear a hood instead
bought it, 3 left
```
