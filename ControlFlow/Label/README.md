# Label

Aim `break` and `continue` at an outer loop by giving it a label.

**You'll need:** [For](https://rux-lang.dev/docs/learn/for), [Break](https://rux-lang.dev/docs/learn/break), [Continue](https://rux-lang.dev/docs/learn/continue)

```sh
rux run
```

```text
6^2 + 8^2 = 100
found after 38 checks
row 1: no product above 10
row 2: 2 x 6 = 12
row 3: 3 x 4 = 12
row 4: 4 x 3 = 12
```

Read the lesson: https://rux-lang.dev/docs/learn/label
