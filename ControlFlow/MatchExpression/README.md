# MatchExpression

Use `match` as an expression whose arms produce the value.

**You'll need:** [Match](https://rux-lang.dev/docs/learn/match), [Ternary](https://rux-lang.dev/docs/learn/ternary)

```sh
rux run
```

```text
day 6 is a weekend (weekend the long way)
month 4 has 30 days
3 cups of size 2 cost 12
the sign says come in
```

Read the lesson: https://rux-lang.dev/docs/learn/match-expression
