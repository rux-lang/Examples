# Block

Use a plain block `{ ... }` as a scope of its own and as a value that yields its last expression, and put one in parentheses when it is a condition.

**You'll need:** [Ternary](https://rux-lang.dev/docs/learn/ternary), [MatchExpression](https://rux-lang.dev/docs/learn/match-expression)

```sh
rux run
```

```text
inside: step 5, total 10
after:  total 10
area 12
a square of side 4 holds at least 12 cells
```

Read the lesson: https://rux-lang.dev/docs/learn/block
