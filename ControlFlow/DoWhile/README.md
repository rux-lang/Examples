# DoWhile

Run a loop body first and test afterwards with `do { } while condition;`, so the body runs at least once.

**You'll need:** [While](https://rux-lang.dev/docs/learn/while)

```sh
rux run
```

```text
while ran 0 times, do-while ran 1 time
4096 has 4 digits
0 has 1 digit
the while version says 0 has 0 digits
```

Read the lesson: https://rux-lang.dev/docs/learn/do-while
