# For

Walk every value of a range with `for name in range`.

**You'll need:** [Range](https://rux-lang.dev/docs/learn/range), [Continue](https://rux-lang.dev/docs/learn/continue)

```sh
rux run
```

```text
1..5:  1 2 3 4
1..=5: 1 2 3 4 5
the faces of a die add up to 21
10! = 3628800
3..3 ran the body 0 times
odd numbers below 10: 1 3 5 7 9
```

Read the lesson: https://rux-lang.dev/docs/learn/for
