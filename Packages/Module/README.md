# Module

Split one package across several source files, group their contents with `module A::B { }`, and import items or whole modules.

**You'll need:** [Function](https://rux-lang.dev/docs/learn/function), [Const](https://rux-lang.dev/docs/learn/const)

```sh
rux run
```

```text
rectangle 3 x 4 area      12
rectangle 3 x 4 perimeter 14
circle radius 4 area      50.26544
circle radius 4 perimeter 25.13272
```

Read the lesson: https://rux-lang.dev/docs/learn/module
