# SourceLibrary

Write a library that is compiled into the program using it, so its generic code serves that program's own types.

**You'll need:** [Dependency](https://rux-lang.dev/docs/learn/dependency), [Generic](https://rux-lang.dev/docs/learn/generic), [Slice](https://rux-lang.dev/docs/learn/slice)

The library is in `Stats/`. It can be checked there, but only the program builds and runs:

```sh
rux run
```

```text
highest score 95
highest price 19.99
```

Read the lesson: https://rux-lang.dev/docs/learn/source-library
