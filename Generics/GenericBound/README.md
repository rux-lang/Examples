# GenericBound

Bound a type parameter by an interface — `<T: Scored>` — so the generic can call its
methods, and see that a primitive qualifies only through an implementation.

**You'll need:** [Generic](https://rux-lang.dev/docs/learn/generic), [Interface](https://rux-lang.dev/docs/learn/interface), [Extension](https://rux-lang.dev/docs/learn/extension)

```sh
rux run
```

```text
margin       5
best number  9
```
