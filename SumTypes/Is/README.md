# Is

Ask which member a sum holds — `token is Number`, `token is (Plus | Minus)` — and get a `bool`
back, without unpacking anything.

**You'll need:** [SubsetPattern](https://rux-lang.dev/docs/learn/subset-pattern), [For](https://rux-lang.dev/docs/learn/for), [Array](https://rux-lang.dev/docs/learn/array)

```sh
rux run
```

```text
2 numbers, 3 operators
starts with a name: true
ends with a number: true
```
