# SumWidening

Pass a smaller sum — `Square | Rectangle` — where a larger one — `Circle | Square | Rectangle` —
is expected, and see that the value keeps its member.

**You'll need:** [SubsetPattern](https://rux-lang.dev/docs/learn/subset-pattern), [Is](https://rux-lang.dev/docs/learn/is)

```sh
rux run
```

```text
areas 4.0 and 2.5
square    side 2.0
rectangle 1.0 by 2.5
square    side 2.0
circle    radius 0.5
```

Read the lesson: https://rux-lang.dev/docs/learn/sum-widening
