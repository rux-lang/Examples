# OptionalPropagate

Pass absence up to the caller with `?` in a function that returns an optional.

**You'll need:** [Presence](https://rux-lang.dev/docs/learn/presence), [Coalesce](https://rux-lang.dev/docs/learn/coalesce)

```sh
rux run
```

```text
#10 leads #7 by 13
#10 against #3: no answer, #3 is not on the team
starters total: 45
mixed total:    -1
```

Read the lesson: https://rux-lang.dev/docs/learn/optional-propagate
