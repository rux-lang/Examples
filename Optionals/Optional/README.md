# Optional

Write a value that may be absent as `T?`, with `none` for absence and a plain value becoming present on its own.

**You'll need:** [Variant](https://rux-lang.dev/docs/learn/variant), [VariantMatch](https://rux-lang.dev/docs/learn/variant-match)

```sh
rux run
```

```text
known: 42
unknown: none
first even of 3, 7, 8, 9: 8
first even of 1, 3, 5, 7: none
```

Read the lesson: https://rux-lang.dev/docs/learn/optional
