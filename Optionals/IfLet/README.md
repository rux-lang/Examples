# IfLet

Bind a present value right in a condition with `if let value? = optional`, add conditions with `&&`, loop with `while let`, and see that `is` only tests.

**You'll need:** [Presence](https://rux-lang.dev/docs/learn/presence), [VariantMatch](https://rux-lang.dev/docs/learn/variant-match), [MutatingMethod](https://rux-lang.dev/docs/learn/mutating-method), [While](https://rux-lang.dev/docs/learn/while)

```sh
rux run
```

```text
#7 scored 12
#9 is not on the team
#10 is the top scorer
#4 after a hat-trick: 3
replay:
  goal by #7
  foul by #4
  the game is paused
  goal by #10
```
