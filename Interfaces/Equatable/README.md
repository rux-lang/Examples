# Equatable

State what equality means for a type by implementing Core's `Equatable` and its `Equals` method.

**You'll need:** [Interface](https://rux-lang.dev/docs/learn/interface), [Reference](https://rux-lang.dev/docs/learn/reference)

```sh
rux run
```

```text
1/2 equals 2/4: true
1/2 equals 1/3: false
itself:     true
either way: true
in a chain: true
halves in the pile: 3
```

Read the lesson: https://rux-lang.dev/docs/learn/equatable
