# InterfaceValue

Borrow values of different types as one interface, and let dynamic dispatch pick the method.

**You'll need:** [Interface](https://rux-lang.dev/docs/learn/interface), [Reference](https://rux-lang.dev/docs/learn/reference)

```sh
rux run
```

```text
holding a circle with area 12.56
holding a rectangle with area 2.0
total area 14.56
the balloon's area is 12.56, and the view sees 12.56
```

Read the lesson: https://rux-lang.dev/docs/learn/interface-value
