# InterfaceValue

Hold values of different types in one interface-typed variable, and let dynamic dispatch pick the method.

**You'll need:** [Interface](https://rux-lang.dev/docs/learn/interface), [Copy](https://rux-lang.dev/docs/learn/copy)

```sh
rux run
```

```text
holding a circle with area 12.56
holding a rectangle with area 2.0
total area 14.56
the balloon's area is 12.56, the photo's is 3.14
```

Read the lesson: https://rux-lang.dev/docs/learn/interface-value
