# Display

Make a type of your own printable with `{}` by implementing `Display`, whose `WriteDisplay` returns `! FormatError`.

**You'll need:** [InterfaceParameter](https://rux-lang.dev/docs/learn/interface-parameter), [UnitFallible](https://rux-lang.dev/docs/learn/unit-fallible), [Propagate](https://rux-lang.dev/docs/learn/propagate)

```sh
rux run
```
