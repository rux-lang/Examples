# Interface

Declare an interface and make a type keep its promise with `extend T : I`.

**You'll need:** [Method](https://rux-lang.dev/docs/learn/method), [Extension](https://rux-lang.dev/docs/learn/extension)

```sh
rux run
```

```text
a circle with area 12.56
a rectangle with area 1.8
is the door square? false
```
