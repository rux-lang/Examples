# InterfaceParameter

Pass any implementing type to a function through a borrowed `&I` or `&var I` parameter.

**You'll need:** [InterfaceValue](https://rux-lang.dev/docs/learn/interface-value), [MutableReference](https://rux-lang.dev/docs/learn/mutable-reference), [MutatingMethod](https://rux-lang.dev/docs/learn/mutating-method)

```sh
rux run
```

```text
the thermostat reads 19
the volume reads 7
the thermostat reads 24
the volume reads 10
heating.degrees is now 24
```
