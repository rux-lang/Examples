# Iterator

Make a type walkable by `for` with a `Next` method that returns `T?`.

**You'll need:** [Interface](https://rux-lang.dev/docs/learn/interface), [For](https://rux-lang.dev/docs/learn/for), [Optional](https://rux-lang.dev/docs/learn/optional), [CoalesceExit](https://rux-lang.dev/docs/learn/coalesce-exit)

```sh
rux run
```

```text
for:     5 4 3 2 1 liftoff
by hand: 5 4 3 2 1 liftoff
anything left? false
```

Read the lesson: https://rux-lang.dev/docs/learn/iterator
