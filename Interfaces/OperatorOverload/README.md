# OperatorOverload

Define `+`, `==` and other operators for a type of your own.

**You'll need:** [Method](https://rux-lang.dev/docs/learn/method), [Constructor](https://rux-lang.dev/docs/learn/constructor), [StructuralEquality](https://rux-lang.dev/docs/learn/structural-equality)

```sh
rux run
```

```text
rent + food = 155050 cents
rent - food = 84950 cents
rent * 3    = 360000 cents
rent == 120000 cents: true
food < rent:          true
```

Read the lesson: https://rux-lang.dev/docs/learn/operator-overload
