# Indexer

Read and write a type of your own with square brackets by declaring `func []` and `func []=`.

**You'll need:** [OperatorOverload](https://rux-lang.dev/docs/learn/operator-overload), [EnumValue](https://rux-lang.dev/docs/learn/enum-value), [MutatingMethod](https://rux-lang.dev/docs/learn/mutating-method)

```sh
rux run
```

```text
Monday 18, Tuesday 21, Friday 25
Friday, corrected: 22
Sunday 0
```

Read the lesson: https://rux-lang.dev/docs/learn/indexer
