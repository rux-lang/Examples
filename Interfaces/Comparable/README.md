# Comparable

Order values of a type by implementing Core's `Comparable`, whose `Compare` answers with an `Ordering`.

**You'll need:** [Equatable](https://rux-lang.dev/docs/learn/equatable), [Enum](https://rux-lang.dev/docs/learn/enum), [MatchExpression](https://rux-lang.dev/docs/learn/match-expression)

```sh
rux run
```

```text
1.9.4 is older than 1.10.0
1.10.0 is newer than 1.9.4
1.9.4 is the same as 1.9.4
newest: 2.0.1
```

Read the lesson: https://rux-lang.dev/docs/learn/comparable
