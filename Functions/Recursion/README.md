# Recursion

Solve a problem with a function that calls itself, stopping at a base case.

**You'll need:** [Function](https://rux-lang.dev/docs/learn/function), [Return](https://rux-lang.dev/docs/learn/return)

```sh
rux run
```

```text
Factorial(1) = 1
Factorial(2) = 2
Factorial(3) = 6
Factorial(4) = 24
Factorial(5) = 120
Factorial(6) = 720
Gcd(48, 18) = 6
Gcd(17, 5) = 1
4 3 2 1 | 1 2 3 4 
```

Read the lesson: https://rux-lang.dev/docs/learn/recursion
