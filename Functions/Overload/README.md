# Overload

Give several functions one name and let each call's arguments choose between them.

**You'll need:** [Function](https://rux-lang.dev/docs/learn/function), [Return](https://rux-lang.dev/docs/learn/return), [Character](https://rux-lang.dev/docs/learn/character)

```sh
rux run
```

```text
an integer: 42
a number with a fraction: 2.5
a truth value: true
a character: R
square           16
rectangle        20
float rectangle  3.0
```

Read the lesson: https://rux-lang.dev/docs/learn/overload
