# Function

Write functions that take typed parameters and give back a result, and call them from `Main`.

**You'll need:** [Mutable](https://rux-lang.dev/docs/learn/mutable), [Float](https://rux-lang.dev/docs/learn/float), [For](https://rux-lang.dev/docs/learn/for)

```sh
rux run
```

```text
Add(2, 3)                    5
Square(7)                    49
Average(4.0, 7.0)            5.5
CelsiusToFahrenheit(100.0)   212.0
SumUpTo(10)                  55
side                         9
Square(Add(1, 2))            9
Add(Square(3), Square(4))    25
```
