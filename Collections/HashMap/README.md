# HashMap

Store values under text keys in a `HashMap<K, V>`, then look them up, replace them and remove them.

**You'll need:** [Callback](https://rux-lang.dev/docs/learn/callback), [Presence](https://rux-lang.dev/docs/learn/presence), [Coalesce](https://rux-lang.dev/docs/learn/coalesce), [StringLiteral](https://rux-lang.dev/docs/learn/string-literal), [Vector](https://rux-lang.dev/docs/learn/vector)

```sh
rux run
```

```text
entries        3
pears          4
kiwis          not stocked
apples         20 (was 15), 3 entries
removed plums  30
has plums      false
entries        2
```

Read the lesson: https://rux-lang.dev/docs/learn/hash-map
