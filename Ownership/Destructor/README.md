# Destructor

Write a destructor, `func ~T(self: &var T)`, and watch when the compiler runs it.

**You'll need:** [Move](https://rux-lang.dev/docs/learn/move), [Method](https://rux-lang.dev/docs/learn/method)

```sh
rux run
```

```text
    back in Main

    Dee leaves

```
