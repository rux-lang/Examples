# Destructor

Write a destructor, `destructor { ... }` inside `extend`, and watch when the compiler runs it.

**You'll need:** [GiveAway](https://rux-lang.dev/docs/learn/give-away), [Method](https://rux-lang.dev/docs/learn/method)

```sh
rux run
```

```text
a short visit:
    Ada visits
    Ada leaves
    back in Main
swapping the seat:
    Bob leaves
giving away:
end of Main:
    Dee leaves
    Cy leaves
```

Read the lesson: https://rux-lang.dev/docs/learn/destructor
