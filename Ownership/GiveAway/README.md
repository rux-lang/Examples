# GiveAway

Give a value away by writing it bare in a binding, an argument, a return or a field, see the old name become unusable, and lend it with `match &value` to keep it.

**You'll need:** [Copy](https://rux-lang.dev/docs/learn/copy), [Exclusivity](https://rux-lang.dev/docs/learn/exclusivity)

```sh
rux run
```

```text
Ana runs lap 1
Ben runs lap 2
Cleo runs lap 3
laps run: 3
Dev runs lap 1
spare laps: 1
Relay finished with 3 laps
Relay still holds the baton
```

Read the lesson: https://rux-lang.dev/docs/learn/give-away
