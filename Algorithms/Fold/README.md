# Fold

Collapse a slice into one answer with `Fold` and `FoldRight`, passing the step as a named function.

**You'll need:** [Callback](https://rux-lang.dev/docs/learn/callback), [Slice](https://rux-lang.dev/docs/learn/slice), [Literal](https://rux-lang.dev/docs/learn/literal)

```sh
rux run
```

```text
sum        10
product    60
empty sum  0
left       407
right      704
negatives  2
```

Read the lesson: https://rux-lang.dev/docs/learn/fold
