# BinarySearch

Search sorted data in logarithmic time with `BinarySearch`, and bracket duplicates with `LowerBound`
and `UpperBound`.

**You'll need:** [Search](https://rux-lang.dev/docs/learn/search), [Sort](https://rux-lang.dev/docs/learn/sort)

```sh
rux run
```

```text
8 found at 5
4 not found, would go at 2
99 not found, would go at 8
5 runs from 2 to 5, 3 of them
5 found at 2
9 not found, would go at 3
```

Read the lesson: https://rux-lang.dev/docs/learn/binary-search
